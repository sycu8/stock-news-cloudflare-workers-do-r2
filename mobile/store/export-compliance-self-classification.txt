2. PRODUCT DESCRIPTION

   Stock News is a mobile application that displays Vietnam stock market news
   and reference information by loading the developer's website
   (https://stocknews.orangecloud.vn) inside a native iOS shell (Capacitor
   WebView). The app does not execute securities trades or store financial
   account credentials.

3. ENCRYPTION USE

   The app uses encryption ONLY for the following exempt purposes:

   [X] Confidentiality of data in transit (HTTPS / TLS)
   [ ] Proprietary or non-standard encryption algorithms
   [ ] Encryption implemented outside Apple's operating system APIs
   [ ] End-to-end custom cryptography
   [ ] VPN or tunneling beyond standard HTTPS

   Technical details:
   - All network communication uses HTTPS (TLS 1.2/1.3) via Apple's iOS
     networking stack (URLSession / WKWebView / App Transport Security).
   - No proprietary encryption algorithms are implemented.
   - No encryption libraries beyond those provided by Apple iOS.
   - Info.plist key ITSAppUsesNonExemptEncryption is set to NO (false).

4. EXPORT CLASSIFICATION

   This product qualifies for exemption under the U.S. Export Administration
   Regulations (EAR), Category 5 Part 2, because it:

   - Uses only standard encryption (TLS) for authentication and protection
     of data in transit;
   - Does not implement encryption beyond what is available in Apple's
     operating system;
   - Is publicly available as a mass-market mobile application;
   - Is not designed for military, intelligence, or weapons use.

   No CCATS, ERN, or French encryption declaration is required for this
   product's stated use of encryption.
