2. Product description

Stock News displays Vietnam stock market news by loading the developer's website inside a native iOS shell (Capacitor WebView). The app does not execute trades or store financial account credentials.

3. Encryption use

The app uses encryption only for confidentiality of data in transit (HTTPS / TLS).

  • All network traffic uses HTTPS (TLS 1.2/1.3) via Apple's iOS networking APIs (URLSession / WKWebView).
  • No proprietary or non-standard encryption algorithms.
  • No custom encryption beyond Apple's operating system.
  • ITSAppUsesNonExemptEncryption = NO in Info.plist.

4. Export classification

This product qualifies for EAR Category 5 Part 2 exemption: standard TLS for data in transit, mass-market public app, no military use. No CCATS or ERN required for this encryption use.
